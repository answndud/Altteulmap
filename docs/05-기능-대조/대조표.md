# PRD/TRD와 현재 코드 대조표

| 기능/설계 | 현재 코드 근거 | 상태 | 주의 |
| --- | --- | --- | --- |
| 지도 viewport 탐색 | src/worker/routes/places-read.ts, places-read-map-repository.ts, src/features/map | 구현·검증 | 결과 상한과 bbox validation이 있음 |
| 가격 검증 2회 조건 | src/worker/admin/admin-price-review-repository.ts: moderateWorkerPriceReport, src/worker/price-report-identity.ts, src/db/schema-pricing.ts | 구현·부분 검증 | accepted 제보의 distinct user/visitor/report id count가 2 이상일 때 승인 transaction에서 verified. 서로 다른 actor 동시 승인 부하는 미검증 |
| 가격 이력 | price_items/price_reports schema와 detail API | 구현 | merge/정정 정책은 남음 |
| 익명 공개 쓰기 | src/worker/routes/public-write-price-reports.ts, src/worker/public-write-actor.ts, src/worker/routes/public-write-support.ts | 구현·부분 검증 | body cap → schema → actor/rate limit → Turnstile → DB 순서. 실제 공개 abuse와 production token은 미검증 |
| credentials 로그인 | auth-credentials.ts, auth-session.ts | 구현·E2E | demo credential은 운영 설정 확인 필요 |
| Kakao/Naver OAuth | auth-oauth.ts, auth-oauth-support.ts | route/contract 구현 | 실제 provider sandbox 미검증 |
| 북마크 | routes/bookmarks.ts, bookmarks-repository.ts | 구현·E2E | session user 전용 |
| 관리자 권한 | src/worker/routes/admin-support.ts: requireAdminSession, src/worker/routes/admin-prices.ts | 구현·E2E | route마다 서버 role을 재확인하지만 production admin QA는 별도 |
| AI 1차 검수 | schema-moderation, admin validation | 제안 경계만 구현 | 외부 AI 자동 pipeline은 없음 |
| Hyperdrive | src/worker/db.ts: getWorkerDb, wrangler.jsonc | fallback 준비 | HYPERDRIVE optional lookup만 있고 현재 binding은 없음 |
| PostGIS | TRD 권장 | 미확인/미사용 | 현재 SQL 범위 조회는 latitude/longitude index 중심 |
| Sentry/Resend | TRD 권장 | 현재 코드 근거 없음 | 완료 기능으로 말하지 않음 |
| 네이티브 앱/자동 수집/추천 | PRD 비목표 | 제외 | 후속 제품 범위 |

상태는 UI 존재 여부가 아니라 route·권한·저장·검증 근거를 함께 본 결과다.
