# 운영 가이드 안내

현재 운영 대상은 Cloudflare Worker altteulmap, 공개 URL과 Supabase PostgreSQL이다. 이 폴더의 절차는 명령의 존재와 코드 guard를 설명하며, 실제 운영 실행 경험이 없는 항목은 미검증으로 표시한다.

| 절차 | 상태 |
| --- | --- |
| local build/deploy check | 실행·검증 |
| Cloudflare deploy | 이전 작업에서 실행 기록 있음 |
| remote read-only smoke | 실행 기록 있음 |
| production migration | guard와 절차 확인, 매번 실행한 것은 아님 |
| backup/restore | 미검증 |
| rollback rehearsal | 미검증 |
| secret rotation | 미검증 |
| 공개 트래픽 incident response | 미검증 |

상세 Cloudflare 원문은 [deploy-cloudflare.md](../deploy/deploy-cloudflare.md)를 참조한다.
