# 성능 예산

## 측정 범위

`npm run search:benchmark`는 production과 동일한 PostgreSQL 조회를 read-only로 반복 실행한다. 지도 viewport, 전체 검색, 관리자 pending 장소, 관리자 open 신고를 포함하며, query timeout은 기본 4.5초다. 데이터는 삽입하지 않고 측정 시점의 실제 row count를 증적에 기록한다.

```bash
BENCHMARK_DATABASE_URL="$STAGING_DATABASE_URL" \
BENCHMARK_ITERATIONS=20 \
BENCHMARK_WARMUPS=3 \
npm run search:benchmark | tee artifacts/search-benchmark.json
```

## 승인 기준

| 지표 | 목표 | 초과 시 조치 |
| --- | ---: | --- |
| 핵심 조회 p95 | 500ms 이하 | query plan·index·rows read 확인 후 배포 보류 |
| 핵심 조회 p99 | 800ms 이하 | 작업량 상한·timeout·결과 축소 검토 |
| rows read | 10,000 이하 | pagination·bbox·검색 인덱스 수정 |
| response payload | 512KiB 이하 | 목록 요약·결과 상한 수정 |
| DB statement timeout | 4.5초 | 503/ bounded response와 알림 확인 |

`measure-map-api`는 HTTP 경계와 response size를 측정하고, `search:benchmark`는 DB execution time·planning time·실제 rows read·shared read blocks를 측정한다. 둘을 같은 데이터 규모에서 실행해야 애플리케이션 지연과 DB 지연을 구분할 수 있다.

## 최근 baseline

2026-08-25 로컬 Docker PostgreSQL seed 1,002건(활성 1,000건)에서 `BENCHMARK_ITERATIONS=20`, warm-up 3회로 측정했다. 지도 viewport p95/p99는 20/31ms, global search는 40/71ms, 관리자 대기열은 11/12ms였고 모든 시나리오의 payload·rows-read 예산을 통과했다. 이 결과는 10만·100만 staging 규모의 승인 증거가 아니며, 규모별 별도 artifact가 생성되기 전까지 성장 성능 승인을 보류한다.

같은 날 별도 disposable DB에서 10만건(활성 10만건) synthetic fixture를 측정했다. 지도 viewport p95/p99는 4/5ms, global search는 111/143ms, payload 최대 353,502 bytes, plan rows-read 최대 6,004건으로 현재 예산을 통과했다. 100만건 적재는 Docker PostgreSQL 내부 저장소 부족으로 중단했으며, 해당 규모의 결과로 해석하지 않는다.

## 검색 인덱스 판단

검색어 조회는 여러 컬럼의 `ILIKE`를 사용하므로 데이터 증가 시 `pg_trgm` 인덱스의 사용 여부를 `npm run search:analyze`와 `EXPLAIN (ANALYZE, BUFFERS)`로 확인한다. 인덱스가 실제 plan에 사용되지 않거나 relevance·쓰기 비용이 악화되면 FTS 도입 여부를 측정 결과로 결정하며, 최신 dependency나 구조를 근거 없이 추가하지 않는다.

## 증적 규칙

- benchmark 결과에는 생성 시각, 실제 dataset count, 반복 횟수, timeout, scenario별 percentile과 plan metric이 있어야 한다.
- production에서 fixture 삽입·삭제로 성능을 측정하지 않는다. 1만/10만/100만 규모 비교는 분리된 staging clone 또는 승인된 synthetic database에서 수행한다.
- threshold 초과를 성공으로 포장하지 않는다. query timeout·DB unavailable은 API의 bounded 오류와 운영 alert가 함께 확인되어야 한다.
