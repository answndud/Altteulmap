# 면접 복기

## 잘 설명할 수 있는 것

- 왜 Vite SPA + Cloudflare Worker BFF로 단순화했는가
- 익명 제보의 편의성과 abuse 방어를 어떻게 절충했는가
- 가격 검증에서 unique constraint, transaction, 조건부 update가 맡은 역할
- 지도 bbox와 결과 상한이 성능·UX에 미치는 trade-off
- 테스트 통과와 실제 production 운영 검증을 어떻게 구분했는가

## 반드시 한정해서 말할 것

- OAuth route와 실제 provider sandbox 연동은 다르다.
- moderation suggestion schema와 외부 AI 자동 검수 pipeline은 다르다.
- historical p95와 production SLO는 다르다.
- remote read-only smoke와 admin mutation/장애 복구 rehearsal은 다르다.

## 답변 연습 순서

1. 30초 답변으로 제품·구조·현재 한계를 말한다.
2. 2분 답변에서 한 기능의 route → validation → repository → DB → UI 갱신을 설명한다.
3. 꼬리질문에서 미검증 범위와 다음 검증 계획을 말한다.
4. 실제 파일을 열어 함수명과 테스트 명령을 확인한다.
