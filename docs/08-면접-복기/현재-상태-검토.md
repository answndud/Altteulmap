# 현재 상태 검토

기준일 2026-08-14 현재, 코드와 자동 검증은 MVP의 핵심 공개 탐색·제보·가격·회원·admin 흐름을 설명할 수 있는 수준이다. 그러나 “완벽”이나 “production 운영 경험”으로 표현할 수는 없다.

## 강점

- 단일 Worker 경계가 명확하다.
- public write의 validation·actor·Turnstile·rate limit이 분리돼 있다.
- 가격 정합성에 schema constraint, transaction, concurrency smoke가 있다.
- migration과 deploy output에 preflight/check가 있다.
- E2E가 공개·회원·admin·모바일·접근성을 포함한다.

## 남은 위험

- 실제 OAuth/provider sandbox와 production Turnstile token을 확인하지 않았다.
- 공개 abuse, 장애 주입, backup restore, secret rotation을 실행하지 않았다.
- React Router upstream dependency advisory가 남아 있다.
- 장소 merge와 AI provider pipeline은 제품/운영 정책이 먼저 필요하다.

## 문서 품질에 대한 자기 비판

이 문서 세트 자체도 다음을 완료된 사실로 포장하지 않는다.

- 모든 API route의 동일한 검증 매트릭스를 아직 한 표로 자동 생성하지 않았다.
- 성능 결과는 p50/p99와 resource metric이 빠진 historical record다.
- 운영 절차는 실제 backup restore·rollback·secret rotation rehearsal이 아니라 guard와 명령의 설명이다.
- 기존 영문 문서와 새 canonical 문서가 당분간 공존하므로, 문서 변경 시 문서-안내의 source/canonical 관계를 다시 확인해야 한다.

## 30초 답변

“알뜰맵은 Vite React와 Cloudflare Worker BFF, PostgreSQL로 구성한 가격 중심 장소 지도입니다. 비회원 탐색과 제한된 익명 제보를 허용하되 signed session/visitor actor, Turnstile, rate limit, schema constraint와 transaction으로 신뢰 경계를 세웠습니다. 성능은 고정 fixture의 map 측정과 E2E로 확인했고, 실제 provider·공개 트래픽·백업 복구는 아직 운영 검증 범위가 아닙니다.”
