# 면접 복기 문서 안내

이 폴더는 “무엇을 만들었다”보다 “왜 그렇게 설계했고 무엇을 검증하지 못했는가”를 설명하기 위한 자료다. 30초 답변은 [현재 상태 검토](현재-상태-검토.md), 깊은 질문은 [질문 은행](기술-질문-은행.md), 사건의 맥락은 [개발 연대기](개발-연대기.md)를 사용한다.

## 답변 원칙

- 실제 코드 위치를 말한다.
- 테스트 통과와 production 운영 경험을 구분한다.
- 성능 수치에는 fixture·환경·날짜를 붙인다.
- “완벽히 방어” 대신 방어 경계와 남은 risk를 말한다.
- 선택하지 않은 기술은 현재 필요조건과 trade-off로 설명한다.
