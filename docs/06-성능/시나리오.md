# 성능 시나리오

## 지도 탐색

서울 viewport z11, 서울 food category z13, global query를 각각 warm-up 후 반복한다. 장소 수와 response size를 함께 기록한다. bbox가 커질 때 결과 상한 2000이 latency와 UX에 미치는 영향을 따로 본다.

## 브라우저

tests/e2e/performance.spec.ts와 map mobile 시나리오로 initial load, map interaction, detail navigation을 측정한다. 브라우저 성능 값과 API p95를 같은 값으로 해석하지 않는다.

## 장애·포화

DB timeout, connection churn, 503 비율, rate-limit queue 고갈을 별도 실험으로 만든다. production에서 수행하지 말고 disposable 환경에서 fixture와 VU를 명시한다. 현재 이 포화 실험의 실행 결과는 없다.
