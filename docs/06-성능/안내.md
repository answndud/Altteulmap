# 성능 문서 안내

알뜰맵의 성능 문서는 목표와 결과를 분리한다. map:measure의 p95는 특정 fixture와 환경의 측정값이지 공개 트래픽 SLO가 아니다. E2E performance는 브라우저 흐름의 회귀 감지에 사용한다.

현재 확인된 historical evidence:

- 2026-05-08 운영 측정 기록의 map API p95: 서울 viewport 37ms, 서울 음식 카테고리 36ms, global query 224ms.
- 1k seed 전후의 측정이며 현재 공개 트래픽 전체를 대표하지 않는다.
- DB timeout과 connection churn에 따른 Hyperdrive 전환은 아직 trigger가 발생했다는 근거가 없다.

재현 방법은 [측정 방법론](측정-방법론.md)과 [시나리오](시나리오.md)를 따른다. 새 수치는 [결과](결과/2026-07-31-현재-측정.md)에 환경·fixture·commit과 함께 추가한다.
