- 이 문서는 active 상태, blocker, 최근 검증, 다음 액션만 유지한다.

- active 문서 상한:
  - 완료된 작업 0건 유지

  - 모든 active 작업이 끝난 최종 상태는 `현재 active 작업 없음`만 남김
