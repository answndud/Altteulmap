# 데모 데이터 가이드

## 데이터 출처

seed는 src/db/seed.ts에 있고, 공공데이터 import는 scripts/import-goodprice.ts와 data/goodprice/import-meta.json에 기록한다. sourceProvider, sourceExternalId, importBatch 같은 provenance 필드를 운영 데이터와 구분해 사용한다.

## 안전한 절차

1. disposable PostgreSQL을 준비한다.
2. ALLOW_LOCAL_MIGRATION=1 npm run db:migrate를 실행한다.
3. npm run db:seed로 seed를 넣는다.
4. 필요하면 npm run data:goodprice를 별도 local DB에서 실행한다.
5. npm run places:duplicates로 읽기 전용 중복 후보를 확인한다.

production import와 production seed는 이 문서의 데모 절차가 아니다. import는 idempotency key와 batch/provenance를 먼저 검토하고, 실행 전 production DB guard와 backup 정책을 확인해야 한다.
