# 테스트 워크플로

## 계층

| 계층 | 명령/위치 | 검증 대상 |
| --- | --- | --- |
| 정적 | npm run lint, npm run typecheck | TypeScript와 lint |
| unit/contract | npm run test:unit | auth, validation, rate limit, moderation contract |
| quality | npm run verify:quality | dependency audit, dead code, CSP inventory |
| build | npm run cf:build:vite, npm run deploy:check:vite | Worker output와 deploy contract |
| DB | npm run db:migrate, npm run db:seed | disposable PostgreSQL schema/seed |
| smoke | npm run smoke:price-concurrency, npm run smoke:remote | 가격 동시성, 원격 read-only health |
| browser | npm run test:e2e:all | 공개·로그인·admin·모바일·접근성·성능 흐름 |

## 실제 확인된 범위

기존 작업에서 lint, typecheck, unit 19건, build/deploy check, migration contract, disposable PostgreSQL migration/seed, full E2E 24건, accessibility axe, local price concurrency, duplicate analysis, remote read-only smoke를 확인했다. 이 문서는 그 기록을 재현하는 진입점이며, 각 실행의 날짜·commit은 audit와 remediation retrospective 원문을 함께 본다.

## 미검증

실제 공개 트래픽 부하, provider OAuth sandbox, 실제 Turnstile production token, backup restore, secret rotation, 외부 AI 호출 비용·timeout은 통과한 테스트로 표시하지 않는다. remote smoke도 쓰기 없는 read-only 범위이며 운영자 QA와 동일하지 않다.

## 문서 변경 시

코드가 바뀌지 않은 문서 전용 변경에서는 전체 테스트를 반복하지 않는다. 링크·경로·YAML parse와 git diff --check를 우선 확인한다. 코드 주장을 새로 추가한 경우 그 주장을 뒷받침하는 최소 unit 또는 기존 실행 결과를 확인한다.
