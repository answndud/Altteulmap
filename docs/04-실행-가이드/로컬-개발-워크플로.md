# 로컬 개발 워크플로

## 준비

Node.js 20.19 이상, npm, Docker를 준비한다. 저장소 루트에서 npm ci를 실행한다. 로컬 DB를 사용할 때는 docker compose 설정과 DATABASE_URL을 확인한다. secret은 실제 운영 값이 아니라 disposable local 값을 사용한다.

## 실행

1. npm run db:up
2. ALLOW_LOCAL_MIGRATION=1 npm run db:migrate
3. npm run db:seed
4. npm run dev

mock UI만 확인할 때는 USE_MOCK_DATA=true를 사용하되, DB 정합성 검증 결과로 해석하지 않는다. Vite/Worker 산출물은 npm run cf:build:vite 후 npm run preview로 확인한다.

## 변경 전 확인

- API route 변경: validation, session/actor, rate limit/Turnstile, repository, test를 함께 확인한다.
- schema/migration 변경: drizzle generate와 migration contract를 확인한다.
- UI 변경: API error/empty/loading state와 데스크톱 Chromium 흐름을 확인한다.
- 운영 설정 변경: wrangler binding과 secret의 fail-closed 동작을 확인한다.

## 금지

production DB에 db push, seed, import를 실행하지 않는다. 실제 OAuth·이메일·AI provider를 로컬 테스트에서 호출하지 않는다. 운영 배포는 [배포 절차](../09-운영-가이드/배포-절차.md)의 승인된 흐름을 따른다.
