# 남은 기능과 결정 조건

이 문서는 완료 목록이 아니라, 현재 코드와 운영 근거가 부족해 다음 판단이 필요한 항목만 기록한다.

| 항목 | 현재 근거 | 다음 결정 조건 | 우선순위 |
| --- | --- | --- | --- |
| 장소 merge mutation | 후보 분석 script는 있으나 merge rollback UX가 없음 | 원본·대상 보존, 가격/댓글/bookmark/report 이전, dry-run과 rollback 설계 | P1 |
| 실제 OAuth sandbox | callback route와 unit contract는 있음 | Kakao/Naver test app에서 redirect, state, code replay, account linking 검증 | P1 |
| AI provider pipeline | suggestion schema/admin 경계만 있음 | provider, 비용 상한, queue, timeout/retry, 개인정보 정책 확정 | P2 |
| Hyperdrive | optional fallback 코드만 있고 wrangler binding 없음 | map p95·DB timeout·connection churn 기준을 반복 관찰 | P2 |
| 백업·복구 | 운영 DB가 Supabase라는 설정만 확인 | 실제 백업 보존 정책과 disposable restore rehearsal | P1 |
| 가격 대표값 정책 | 최신 승인 가격과 검증 계산이 구현됨 | 폐업·가격 급변·동일 항목 Unicode 정규화 사례 추가 | P2 |

각 항목은 구현 전 별도 계획과 검증 명령을 만든다. 문서에 적힌 결정 조건을 충족하지 않은 상태에서 “완료”로 이동하지 않는다.
