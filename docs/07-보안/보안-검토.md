# 보안 검토

| 경계 | 코드 근거 | 확인 상태 | 남은 확인 |
| --- | --- | --- | --- |
| session 서명/만료 | src/worker/auth/session.ts | unit/route 근거 있음 | key rotation rehearsal |
| OAuth state | src/worker/routes/auth-oauth.ts | malformed/state contract 테스트 | 실제 Kakao/Naver sandbox |
| admin role | src/worker/routes/admin-* | E2E와 route guard | production admin QA |
| public write | src/worker/public-write-actor.ts, public-write-* | unit/E2E 일부 | 공개 abuse/Turnstile token |
| body cap | src/worker/index.ts | unit 근거 | proxy/WAF 최대 body와의 운영 조합 |
| DB fail closed | src/worker/db.ts, health.ts | local/remote read-only | 실제 장애 주입 |
| CSP/header | public/_headers, worker middleware | csp inventory/smoke | 외부 도메인별 browser 운영 확인 |
| dependency | package-lock.json | npm audit 실행 | upstream advisory 공개 fix |

P0/P1로 단정할 수 있는 미검증 문제는 현재 기록하지 않는다. 다만 production provider, 공개 abuse, 장애 주입을 실행하지 않았으므로 “보안 완료”가 아니라 “코드 경계와 자동 검증 확인”으로 표현한다.

## 위협 모델과 잔여 위험

| 위협 | 현재 방어 | 남는 위험 | 확인 방법 |
| --- | --- | --- | --- |
| visitor cookie 위조 | AUTH_SECRET HMAC, UUID/expiry 검증 | secret 유출·rotation 전환, cookie 폐기 전까지의 actor 지속 | session unit + rotation rehearsal 필요 |
| visitor cookie 재발급 | persistent rate limit과 visitor/user key | header fallback이나 새 actor를 통한 분산 abuse | disposable DB abuse simulation 필요 |
| IP spoofing | Cloudflare CF-Connecting-IP를 Turnstile remoteip에 전달 | actor key는 x-forwarded-for fallback을 직접 읽음 | Cloudflare 실제 header contract 확인 |
| Turnstile 우회 | localhost만 bypass, secret 없으면 503 | production hostname 판단과 proxy 환경 오류 | deployed token test 필요 |
| OAuth CSRF/replay | signed state, cookie state equality, nonce/provider check, 10분 expiry | provider sandbox와 code replay 실제 검증 없음 | provider test app |
| admin IDOR | requireAdminSession + target/status query | 모든 admin mutation의 production QA 범위 | route matrix + read-only/admin test |
| 저장형 XSS | Zod/CSP/렌더링 경계 | sanitization 정책과 링크 spam 검증 부족 | malicious fixture/browser test |
| DB 장애 은닉 | 503와 no-store, mock fallback 금지 | 실제 장애 주입과 recovery time 미측정 | disposable DB failure injection |
