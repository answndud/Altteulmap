# 모듈 지도

## 모듈별 책임

| 영역 | 주요 위치 | 설명 |
| --- | --- | --- |
| client app | src/client/App.tsx, src/client/routes | 공개·회원·admin 화면과 route composition |
| map feature | src/features/map | Naver Maps, marker/list, viewport interaction |
| Worker composition | src/worker/index.ts | middleware, route 등록, static fallback |
| auth | src/worker/auth, src/worker/routes/auth-* | credentials, OAuth, signed session |
| public writes | src/worker/public-write-actor.ts, src/worker/routes/public-write-* | visitor actor, Turnstile, body/rate limit, write |
| reads | src/worker/routes/places-read.ts, places-read-map-repository.ts | bbox/list/detail 조회 |
| repositories | src/worker/*-repository.ts | Drizzle query와 정합성 mutation |
| admin | src/worker/admin, src/worker/routes/admin-* | role boundary, queue, CAS, action |
| persistence | src/db/schema*.ts, drizzle | schema, migration, seed |
| verification | tests, scripts | unit, E2E, smoke, import, deploy check |

## 의존 방향

client는 route API 계약에 의존하고 DB에는 의존하지 않는다. route는 validation/auth helper와 repository를 호출한다. repository는 schema와 DB client에 의존한다. scripts는 운영 목적에 따라 별도 guard를 갖고 애플리케이션 route를 우회하지 않는다.

## 파일 선택 기준

새 public API는 src/worker/routes와 해당 repository/test를 함께 검토한다. DB schema 또는 migration은 .agents/skills/database-migrations/SKILL.md의 저장소 규칙을 따른다. UI 변경은 src/client와 관련 E2E를 함께 확인한다.
